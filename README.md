# Arkbridge 360 Membership App

Mobile-friendly React/Vite frontend for the Supabase membership and staff database.

## Setup
1. Copy `.env.example` to `.env.local`.
2. Set `VITE_SUPABASE_URL` to your Supabase project URL.
3. Set `VITE_SUPABASE_PUBLISHABLE_KEY` to the project's publishable key.
4. Run `npm install` then `npm run dev`.

The app uses Supabase Auth and the secure RPC functions created in the database.
